## Project Overview

This is an educational repository for the OTUS JavaScript QA Engineer course. It contains course materials, lessons, and practical tasks focused on test automation using JavaScript.

## Repository Structure

- `/lessons/` - Course lessons in Markdown format covering topics like API testing, UI testing, CI/CD, and JavaScript fundamentals
- `/tasks/` - Practical assignments and exercises corresponding to each lesson
- `/qa/` - Q&A materials and answers
- `/docs/` - Additional documentation
- `/server/` - Server configuration for the course (uses Nginx Proxy Manager)
- `/assets/` - Course assets and resources
- `/other/` - Miscellaneous materials

## Content Type

This is a **documentation-only repository** containing course materials in Markdown format. There is no executable code, test suites, or build configuration to run.

## Key Topics Covered

The course covers:
- JavaScript fundamentals for QA engineers
- API testing with JavaScript libraries
- UI testing with Playwright
- CI/CD practices with GitHub Actions and GitLab
- TypeScript in testing
- SQL for testers
- Docker and containerization
- BDD and acceptance testing
- Design patterns in test automation

## Working with This Repository

Since this is a course materials repository:
- Focus on content accuracy and clarity when making edits
- Maintain consistent formatting across lesson and task files
- Ensure examples and code snippets in markdown files are correct and educational
- Cross-reference between lessons and their corresponding practice tasks as shown in README.md
