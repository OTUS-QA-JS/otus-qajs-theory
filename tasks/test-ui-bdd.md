# BDD: Cucumber + Playwright

## Цель
Освоить написание acceptance-тестов в стиле BDD: сценарии на Gherkin, реализация шагов на Cucumber.js и Playwright поверх паттерна PageObject.

## Задание
Опишите **5 сценариев** на языке Gherkin и реализуйте их шаги.

Тестируем сайт https://www.saucedemo.com/

1. Подключите к проекту `@cucumber/cucumber` и `playwright`.
2. Опишите feature-файлы: сценарии формулируем от лица пользователя, без упоминания локаторов, кликов и селекторов.
3. Реализуйте step definitions поверх **Page Object'ов** — шаг вызывает метод страницы, а не работает с локаторами напрямую.
4. Используйте `Background` для общей предусловной части и хотя бы один `Scenario Outline` с `Examples` для параметризации.
5. Настройте `World` и хуки (`Before` / `After`), чтобы браузер и страница создавались на каждый сценарий и корректно закрывались.
